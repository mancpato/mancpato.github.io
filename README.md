<!-- 
Para correr: levantar el servidor con
        bundle exec jekyll serve

y visualizar la págia en el navegador:
        http://127.0.0.1:4000/


Si no se ha instalado Ruby antes:

        sudo apt install ruby-full build-essential zlib1g-dev

# Configurar gems en tu home, no en el sistema
        echo 'export GEM_HOME="$HOME/gems"' >> ~/.bashrc
        echo 'export PATH="$HOME/gems/bin:$PATH"' >> ~/.bashrc
        source ~/.bashrc

# Instalar bundler y jekyll
        gem install bundler jekyll

# En la carpeta de tu sitio, instalar las dependencias del proyecto
        bundle install


O más pro sin instalar en el sistema:
        docker run --rm -v "$PWD:/srv/jekyll" -p 4000:4000 jekyll/jekyll jekyll serve
