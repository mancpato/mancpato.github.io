### TalleRNA {#TalleRNA}

Este proyecto permite comparar redes neuronales pequeñas (perceptrones multicapa) variando algún hiperparámetro. El repositorio se encuentra en [github.com/mancpato/TalleRNA](https://github.com/mancpato/TalleRNA). Se espera que sea útil para cualquier interesado en estudiar redes neuronales.

Para visualizar una sóla red aprendiendo, se recomienda el excelente recurso [Playground de TensorFlow](https://playground.tensorflow.org/), muy instructivo, elocuente y bellamente diseñado.

Es parte de un proyecto mayor al que llama **SuiteRNA** que sigo elaborando.
